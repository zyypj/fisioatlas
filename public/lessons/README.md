# Esquema de articulação sinovial

Construído por script original no Blender do Higgsfield 3D Jutsu.

- Projeto: https://higgsfield.ai/3d-jutsu/7d5ee5e8-869c-40f7-9c82-86a2c6d4f0ba
- Revisão: 1, operação fisioatlas-synovial-teaching-model-02.
- Arquivos: synovial.glb (modelo portátil), synovial.blend (fonte editável), synovial.png (render de conferência).
- Script reproduzível: scripts/higgsfield_joint.py, no projeto FisioAtlas.
- Referência conceitual: https://openstax.org/books/anatomy-and-physiology-2e/pages/9-4-synovial-joints

Oito peças: duas extremidades ósseas, duas cartilagens, cápsula fibrosa em corte, membrana sinovial em corte e dois ligamentos extrínsecos.

Esquema genérico ampliado para explicar a organização de uma articulação sinovial; não representa joelho, ombro ou qualquer articulação específica. O espaço articular e as formas foram simplificados. Não há reconstrução de exames ou geometria de paciente.
